# 研究方法与证据边界

## 数据取得

- 2026-09-09 使用 `yt-dlp` 的 Python API读取公开视频元数据和字幕清单。
- 优先级为人工字幕集合优先、英文优先；实际选择 `en`。另选择 `zh-CN`。
- 两轨均被 `yt-dlp` 列在 `subtitles`（人工字幕）而非仅列在 `automatic_captions`。这只记录平台/工具分类，不能独立证明作者制作、人工翻译或校对质量。
- 原始响应转换为标准 SRT；英文纯文本去掉时间戳，中文文本保留时间戳便于研究。没有下载音频或视频。
- 完整字幕是第三方版权内容，仅存本地 `data/transcripts/`，整个目录被 `.gitignore` 排除。

## 分析流程

1. 校验两条 SRT 均有非空 cue、时间戳格式有效、开始时间非递减、结束晚于开始。
2. 按 00:00–18:49、20:26–38:59、40:55–62:06、63:38–81:08、83:36–结束五段通读中文字幕。
3. 对严格规则、入场、止损、止盈、RR、新闻过滤、部分止盈、现场盈亏等关键语句回查英文 SRT。
4. 将内容分为：作者/主持人的策略陈述、图表历史案例、现场演示、赞助与推广、研究者风险评价。
5. 公开报告只做转述与必要的极短引用，并用时间链接追溯；不公开完整字幕或大段原文。

## 局限

- 没有在本项目中公开或长期保存视频文件；画面信息依据视频中讲者对图表的口头指示和字幕核对。价格点位、合约月份及部分图上日期在口述中不完整。
- 自动或发布者提供的字幕可能误识别专有名词。例如中文轨个别处将 BOS、POI、PDL 或合约数量翻译得不自然，因此关键规则以英文轨为准。
- 三个历史图表案例可能是事后选择。现场段落能降低纯事后讲解问题，但剪辑、账户归属、成交回报、费用与完整连续记录仍未独立验证。
- 本报告是内容分析，不是策略有效性认证。量化草案中的阈值是研究假设，不应倒推为作者原话。
